在使用 Python 的 requests 库进行网络请求时，经常会遇到请求卡住的情况。默认情况下，requests 会无限期等待，这可能导致程序挂起，影响用户体验。

最佳实践总结

场景 推荐方案
简单请求 直接设置 timeout 参数
生产环境 使用 Session + 重试机制
高并发场景 使用 aiohttp 异步请求
API 调用 设置连接超时 3-5 秒，读取超时 10-30 秒

注意事项

  1. 不要设置过短的超时：网络波动可能导致正常请求失败
  2. 区分连接超时和读取超时：连接超时通常更短（3-5秒）
  3. 记录超时日志：便于排查问题
  4. 提供降级方案：超时后返回缓存数据或默认值
